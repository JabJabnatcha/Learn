1. The 5 Core Architecture Styles at a Glance

Monolithic • Technical

Layered (n-tier)

แยกตามบทบาทเชิงเทคนิค (Presentation → Business → Persistence → Database) เรียบง่าย ต้นทุนต่ำ เหมาะสำหรับการเริ่มต้น

Monolithic / Distributed

Microkernel

แยก Core System ออกจาก Plug-in Modules ต่อขยายฟังก์ชันเฉพาะทางหรือกฎระเบียบแต่ละพื้นที่ได้โดยไม่กระทบโค้ดหลัก

Distributed • Technical

Event-Driven

ประมวลผลแบบ Asynchronous ผ่าน Topics/Queues แยกตัวเป็นอิสระ (Decoupled) รองรับ Scalability และ Performance สูงสุด

Distributed • Domain

Microservices

บริการขนาดเล็กแยก Deploy อิสระ ยึดหลัก Bounded Context และ Distributed Data ช่วยให้ส่งมอบและปรับแก้ฟีเจอร์ได้เร็วที่สุด (High Agility)

Distributed • Technical

Space-Based

ทลายคอขวด Database Bottleneck ด้วย In-Memory Data Grid ตัดฐานข้อมูลออกจาก Transaction ปกติ รองรับโหลดพุ่งกระฉูดได้ทันที

2. Interactive Knowledge Checks

Q1: An e-commerce flash sale causes massive traffic surges and severe database bottlenecks. Which architectural style resolves this by eliminating the database from active transactions?
Q2: In Event-Driven Architecture, how does an event differ fundamentally from a message in terms of context and intent?
Q3: In a Layered Architecture, what occurs when 80 percent or more of user requests merely pass through layers without applying any business logic?

3. Real-World Architecture Scenario Matching

🏢 Scenario: Global Insurance Claims Processing

A nationwide insurance enterprise needs to process auto accident claims across 50 states. Each state has unique legal statutes and repair compensation rules, while the standard claim intake and payment payout workflows remain uniform. What is the optimal architecture style?

👉 Optimal Choice: Microkernel Architecture. The core system encapsulates the standardized claim intake, valuation workflow, and accounting payout, while state-specific statutory requirements are isolated into independent, swappable jurisdiction plug-ins!
