Lesson 18: Code Placement & Data Flow Across Layers

เป้าหมายของบทเรียน: เข้าใจอย่างลึกซึ้งและสามารถอธิบายได้ว่า โค้ดแต่ละไฟล์ควรสังกัดอยู่ใน Layer ไหน, รับข้อมูลมาจากใครในรูปแบบใด, ทำงานอะไร และ ส่งผลลัพธ์ต่อไปที่ไหน อย่างไร ตามหลักสถาปัตยกรรมระดับสากล

Lesson Goal: Master the architectural placement of code: know exactly which layer each class belongs to, what input it receives from whom, what responsibility it fulfills, and where and how it dispatches output.

📖 คู่มืออ้างอิงฉบับสมบูรณ์: เปิดอ่านตารางสรุปโค้ดทุกประเภทได้ที่ Code Placement & Data Flow Master Guide

1. การเดินทางของข้อมูล 4 ขั้นตอน (The 4-Stage Flow)

1
Presentation Layer (Controller / Endpoint)

รับ: HTTP Request (JSON) จากผู้ใช้ → แปลงเป็น Request DTO
หน้าที่: ตรวจ Auth, เช็ค Validation เบื้องต้น, ส่งต่อให้ Service
ส่ง: เรียก Application Service แล้วนำผลลัพธ์แปลงเป็น HTTP Status (200, 400) คืนกลับให้ Client

2
Application Layer (Service / Use Case)

รับ: Request DTO จาก Controller
หน้าที่: ผู้กำกับกระบวนการ (Orchestrator) เรียก Repository ดึง Entity, สั่ง Entity คำนวณ, เรียก Payment Gateway, สั่งบันทึก
ส่ง: คืนค่า Response DTO กลับไปให้ Controller

3
Domain Layer (Entities & Pure Rules)

รับ: พารามิเตอร์ดิบผ่าน Method Call จาก Application Service
หน้าที่: ผู้คุมกฎเกณฑ์ธุรกิจสูงสุด (Business Invariants) เช่น ตัดสต็อก, ห้ามติดลบ (Zero Dependency ห้ามรู้จัก DB หรือ HTTP)
ส่ง: เปลี่ยนสถานะตัวเอง (State change) หรือคืนค่าผลลัพธ์คำนวณ

4
Infrastructure Layer (Database, Repositories, Third-party APIs)

รับ: คำสั่งจาก Application Service ผ่าน Interface Contract (เช่น IProductRepository)
หน้าที่: คุยกับโลกภายนอก (SQL DB, Stripe, Email) จัดการเรื่อง I/O จริง
ส่ง: บันทึก DB หรือยิง API สำเร็จ แล้วแปลงผลลัพธ์คืนให้ Application Service

2. แบบฝึกหัดทดสอบการจัดกลุ่มโค้ด (Interactive Code Placement Challenge)

คลิกเลือก Layer ที่ถูกต้องสำหรับโค้ดแต่ละประเภทด้านล่างนี้:

IProductRepository.cs อินเทอร์เฟซกำหนดสัญญาว่าต้องมี GetByIdAsync() และ SaveAsync()
StripePaymentGateway.cs โค้ดเรียกใช้งาน Stripe .NET SDK เพื่อตัดบัตรเครดิตจริงผ่านเครือข่าย
BankAccount.cs คลาสบัญชีที่มีกฎห้ามถอนเกินยอดเงินคงเหลือ และคำนวณดอกเบี้ย
ApiKeyMiddleware.cs ตัวดักจับ HTTP Header 'x-api-key' ก่อนที่จะส่งคำขอเข้าสู่ Controller
