Lesson 4: Abstract Template Method

The abstract base class defines the invariant execution skeleton, forcing sub-nodes to override only specific steps.

public abstract class ReportGenerator
{
    public void GenerateReport()
    {
        OpenConnection();
        var data = FetchData(); // abstract
        var formatted = FormatReport(data); // abstract
        CloseConnection();
    }
}
