Lesson 1: BankAccount State & Behavior

Bundles related state (private field _balance) and behavior (Deposit method) in a single class blueprint.

public class BankAccount
{
    private double _balance;
    public BankAccount(double initial) { _balance = initial; }
    public void Deposit(double amount) { if (amount > 0) _balance += amount; }
    public double GetBalance() => _balance;
}
