Lesson 3: Polymorphism Virtual Dispatch

Inherits baseline properties, but redefines GetDiscountRate using virtual and override dispatch bindings.

public class Customer
{
    public virtual double GetDiscountRate() => 0.0;
}
public class VipCustomer : Customer
{
    public override double GetDiscountRate() => 0.10; // 10%
}
