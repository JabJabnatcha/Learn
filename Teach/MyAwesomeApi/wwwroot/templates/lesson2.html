Lesson 2: Encapsulation Property Validator

Fields are kept private. Modification is only allowed through C# Properties, which validates inputs before saving.

public class Product
{
    private double _price;
    public double Price
    {
        get => _price;
        set => _price = value >= 0 ? value : 0; // Rejects negative
    }
}
