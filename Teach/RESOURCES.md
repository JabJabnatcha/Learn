# OOP and Software Architecture Resources

## Knowledge

- [Website: Refactoring.Guru](https://refactoring.guru)
  เว็บไซต์สอนเรื่อง Refactoring, SOLID Principles และ Design Patterns ที่ดีที่สุด มีตัวอย่างโค้ดทั้งภาษา C++, C#, และ Java พร้อมคำอธิบายและรูปภาพประกอบที่เข้าใจง่ายมาก
- [Book: _Head First Design Patterns_ — Eric Freeman & Elisabeth Robson](https://www.oreilly.com/library/view/head-first-design/9781492077992/)
  หนังสืออธิบาย Design Patterns ยอดนิยมที่ใช้การเล่าเรื่องและรูปภาพประกอบที่จำง่าย ใช้ Java เป็นหลักในการยกตัวอย่าง เหมาะสำหรับปูพื้นฐาน OOP และ Patterns
- [Book: _Clean Architecture: A Craftsman's Guide to Software Structure and Design_ — Robert C. Martin (Uncle Bob)](https://www.amazon.com/Clean-Architecture-Craftsmans-Software-Structure/dp/0134494164)
  หนังสือที่จำเป็นต้องอ่านสำหรับผู้ที่ต้องการเป็น Software Architect อธิบายวิธีการแยกส่วนระบบ (Decoupling), การวาง Component และการออกแบบสถาปัตยกรรมที่ไม่ขึ้นกับ Framework หรือ Database
- [Book: _Adaptive Code: Agile coding with design patterns and SOLID principles_ — Gary McLean Hall](https://www.microsoftpressstore.com/store/adaptive-code-agile-coding-with-design-patterns-9781509302581)
  หนังสือสอนหลักการ SOLID และการประยุกต์ใช้ใน C# / .NET ได้ดีมาก ช่วยให้เข้าใจการออกแบบโค้ดที่สามารถปรับตัวและรองรับการเปลี่ยนแปลงของธุรกิจได้ง่าย
- [Website: Vue.js Documentation](https://vuejs.org/)
  เอกสารหลักของ Vue.js สำหรับศึกษาการวางโครงสร้าง Component, State Management (Pinia), และ Best Practices ฝั่ง Frontend
- [Website: Tailwind CSS Documentation](https://tailwindcss.com/)
  คู่มือการใช้งาน Utility-first CSS สำหรับออกแบบหน้าจอ UI ที่สวยงามและรวดเร็ว

## Wisdom (Communities)

- [Reddit: r/softwarearchitecture](https://www.reddit.com/r/softwarearchitecture/)
  บอร์ดแลกเปลี่ยนความคิดเห็นด้านการออกแบบโครงสร้างซอฟต์แวร์สถาปัตยกรรมระบบ และข้อดีข้อเสียของแนวทางต่าง ๆ
- [Website: Martin Fowler's Blog](https://martinfowler.com/)
  บทความและแนวคิดสถาปัตยกรรมซอฟต์แวร์ระดับ Enterprise จากผู้ร่วมเขียน Agile Manifesto และผู้แต่งหนังสือ Patterns of Enterprise Application Architecture
