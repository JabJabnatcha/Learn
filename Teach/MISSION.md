# Mission: OOP and Software Architecture for Full-Stack Developers

## Why
เป็น Full Stack Developer ที่สามารถออกแบบและสร้างระบบ Software Architecture ที่มีคุณภาพสูง ยืดหยุ่น และบำรุงรักษาง่าย โดยใช้หลักการ OOP และการออกแบบสถาปัตยกรรมซอฟต์แวร์ในการแก้ปัญหาทางธุรกิจจริงได้อย่างมีประสิทธิภาพ

## Success looks like
- ออกแบบโครงสร้าง Class และ Object ของระบบงานธุรกิจโดยใช้หลักการ SOLID ได้อย่างถูกต้อง
- ประยุกต์ใช้ Design Patterns หลัก ๆ (เช่น Factory, Strategy, Observer, Repository) ใน C++, C# หรือ Java เพื่อแก้ปัญหาโครงสร้างโค้ดที่ซับซ้อน
- สามารถออกแบบและสร้างสถาปัตยกรรมระดับระบบ เช่น Clean Architecture หรือ Layered Architecture ที่แยกส่วน Logic ธุรกิจ ออกจาก UI และ Database ได้อย่างชัดเจน
- พัฒนาเว็บแอปพลิเคชันแบบ Full-Stack ที่เชื่อมต่อระบบ Backend (Java/C#) เข้ากับ Frontend (Vue.js + Tailwind CSS) ได้อย่างเป็นระบบและยืดหยุ่น

## Constraints
- **เวลาที่จำกัดอย่างมาก (1-2 วัน):** ต้องจัดการเรียนการสอนแบบเร่งรัด (Crash Course) ตัดส่วนฟุ่มเฟือยออก และเน้นไปที่การประยุกต์ใช้ SOLID, DI และ .NET โดยตรง
- เน้นภาษา C#/.NET เป็นแกนกลางหลักในการทำความเข้าใจ SOLID และ Dependency Injection
- การเรียนรู้ต้องเน้นการนำไปใช้จริง (Practical application) ในงานธุรกิจ เพื่อให้เข้าใจโครงสร้างระบบ


## Out of scope
- การเขียนโปรแกรมระดับต่ำมากใน C++ (เช่น Driver, Embedded systems, Hardware interfacing)
- การทำ DevOps, CI/CD, Cloud Deployment ระดับลึก (จะโฟกัสที่การออกแบบโครงสร้างซอฟต์แวร์เป็นหลัก)
