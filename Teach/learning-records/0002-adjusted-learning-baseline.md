# Adjusted Learning Baseline and Teaching Strategy

ผู้เรียนมีระดับความรู้แบบมือใหม่ในการเขียนโค้ดจริง แม้จะเคยเรียนทฤษฎีระดับสูง เช่น Clean Architecture, SDLC และ TDD มาบ้างแต่ข้อมูลยังกระจัดกระจายและจำ syntax ไม่ค่อยได้ เพื่อสร้างความมั่นใจและป้องกันการรับข้อมูลมากเกินไป (Cognitive Overload) เราจึงปรับกลยุทธ์โดยใช้ C# เป็นภาษาหลักในการสอน Backend OOP และแบ่งบทเรียนย่อยให้ลงมือทำจริงมากขึ้น
